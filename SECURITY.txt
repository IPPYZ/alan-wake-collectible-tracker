Alan Wake Collectible Tracker — Security & Privacy
Version 2.6.6

WHAT THIS PROGRAM DOES
  - Reads Alan Wake / American Nightmare save files (config) to count collectibles.
  - Reads the Steam installation and loginusers.vdf to show account names.
  - Reads Documents\Remedy\... folders and scans fixed drives for the save signature.
  - Writes ONLY:
      * Backups\<game>_<date>.bak next to the EXE (automatic + manual backups)
      * %APPDATA%\AlanWakeTracker\settings.json (language, last save, filters)
      * %APPDATA%\AlanWakeTracker\log.txt (only if the app crashes)
      * export files the user explicitly saves
  - It NEVER writes to the game save or to the game folder.
  - It opens NO network connections, sends no telemetry, and has no updater.

UNSIGNED BINARY
  The EXE is not code-signed. Windows SmartScreen may show
  "Windows protected your PC" on first run.

ANTIVIRUS FALSE POSITIVES
  Unsigned .NET applications are sometimes flagged heuristically.
  The complete behaviour is listed above; there is no packing, no obfuscation,
  no network code and no persistence (no services, no startup entries).
